# EasyLedger 簡單記帳

EasyLedger 是一款以「快速、清楚、容易持續」為核心的繁體中文記帳介面原型。專案以台灣使用情境設計，預設幣別為新台幣（TWD），目前可在手機與桌面瀏覽器操作。

## 線上操作

[開啟 EasyLedger 可操作原型](https://easy-ledger-prototype.chienfaweng.chatgpt.site)

> 目前為前端操作原型，資料只保留在當次瀏覽狀態，尚未連接正式會員系統、資料庫或雲端同步。

## 目前功能

### 首頁

- 月份切換
- 總資產顯示與金額隱藏
- 當月收入、支出及結餘摘要
- 預算使用進度
- 最近交易紀錄

### 快速記帳

- 新增支出、收入及轉帳
- 支出與收入使用不同分類
- 轉帳設定轉出與轉入帳戶
- 檢查轉出、轉入帳戶不可相同
- 新增交易後即時更新畫面

### 交易明細

- 依支出、收入及轉帳篩選
- 顯示交易分類、日期、帳戶及金額
- 查看交易詳細內容
- 刪除交易與操作提示

### 報表

- 前後月份切換及跨年度切換
- 收入、支出及本月結餘摘要
- 支出分類圓餅圖
- 近六個月趨勢圖
- 依全部帳戶、現金、銀行或電子支付篩選

### 我的帳戶

- 帳戶管理與新增帳戶 UI
- 分類管理
- 預算管理
- 固定收支
- 通知設定
- 外觀與安全
- 資料匯出
- 說明中心

## 技術架構

- React 19
- Next.js 16
- TypeScript 5
- Vinext／Vite
- Tailwind CSS 4
- Cloudflare Worker 相容建置
- Drizzle ORM（預留資料庫整合）

## 專案結構

```text
app/
├── page.tsx          # 主要介面、狀態與互動
├── globals.css       # 全域樣式與響應式版面
└── layout.tsx        # 頁面配置

db/                   # 資料庫與結構預留
public/               # 公開靜態資源
scripts/              # 安裝、建置及驗證腳本
tests/                # 渲染驗證測試
worker/               # 部署入口
```

## 本機執行

### 環境需求

- Node.js 22.13.0 以上
- npm
- 建議使用 Linux、WSL 或相容的 Shell 環境

### 安裝與啟動

```bash
npm ci
npm run dev
```

啟動後依終端機顯示的本機網址開啟網站。

### 常用指令

```bash
npm run dev                # 啟動開發環境
npm run build              # 建置並驗證部署檔案
npm test                   # 執行建置與渲染測試
npm run lint               # 檢查程式碼
npm run validate:artifact  # 驗證既有部署產物
```
